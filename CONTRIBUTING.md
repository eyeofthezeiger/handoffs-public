# Contributing

Every change comes in as a pull request. Nothing is pushed straight to `main`, and only the owner merges.

## Before you open a pull request

- [ ] It starts from `templates/handoff.md` and follows the naming rule in the README.
- [ ] It sits in the right area folder: `agents/`, `builds/`, `research/` or `ops/`.
- [ ] No company, client or colleague names.
- [ ] No internal URLs, hostnames, account ids, chat channels or ticket keys.
- [ ] No secrets, tokens, `.env` values or connection strings.
- [ ] No personal details: address, schedule, health, money.
- [ ] No customer or user data, even as examples.
- [ ] Company-specific tools and stack swapped for generic ones.
- [ ] Front matter has `visibility: public`.
- [ ] The secret scan check passes on the pull request.

Agents may open pull requests here. They never merge them.
